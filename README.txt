- `images/camry.jpg` — รูปรถที่เจ้าของเว็บไซต์ส่งมา ใช้ในแกลเลอรี่ Toyota Camry

## เผยแพร่ด้วย GitHub Pages ฟรี
1. ดาวน์โหลดและแตกไฟล์ ZIP
2. สร้าง Repository ใหม่ เช่น `taxi-car-service`
3. อัปโหลดไฟล์และโฟลเดอร์ทั้งหมด โดยให้ `index.html` อยู่ที่ root และคงโฟลเดอร์ `images` ไว้
4. ไปที่ Settings → Pages
5. เลือก `Deploy from a branch` → Branch `main` → Folder `/ (root)` → Save
6. รอ GitHub เผยแพร่เว็บไซต์ แล้วเปิด URL ที่ GitHub Pages แสดงให้
